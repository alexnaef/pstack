### Author or edit a skill

1. Check the skill's existing frontmatter, links, and references. For a new local skill, choose `.agents/skills/<name>/SKILL.md` for Codex or `.claude/skills/<name>/SKILL.md` for Claude Code.
2. Give it a matching `name` and a description that says when to use it. Put longer conditional instructions in linked files.
3. Preserve behavior outside the requested change. Apply [Unslop](../../unslop/SKILL.md) where it helps.
4. Check that referenced files resolve and walk a realistic prompt through the result. Prepare a local review.
