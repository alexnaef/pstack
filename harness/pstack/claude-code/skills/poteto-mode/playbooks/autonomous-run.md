### Autonomous run

1. State a clear, locally checkable exit condition, such as a passing reproduction, unchanged screenshots, or a measured target.
2. Work in the current local session. Wait for known local commands to finish using their completion status. If an app must start first, use a bounded health check.
3. Run the smallest experiment that advances the goal. Verify it, keep changes supported by evidence, and discard only your own failed experiment. Use separate local worktrees for concurrent edits.
4. Record each useful iteration with [Show me your work](../../show-me-your-work/SKILL.md). Respect the run's authorization. Keep side work separate.
5. Stop when the condition passes, the agreed budget runs out, or the missing evidence makes the next step impossible. State the final check and any remaining work.
